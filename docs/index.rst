CPU_FPGA documentation
======================

A pipelined RV32IM CPU implemented in VHDL, with an internal bootloader
BRAM, an external SDRAM controller, and a small set of memory-mapped
peripherals (UART, GPIO, timer), targeting an Intel/Altera Cyclone IV FPGA.
